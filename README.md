AI-based Video Summarizer is developed as an intelligent solution that can automatically analyze video content and generate concise summaries. The system works by extracting audio from videos, converting speech into text using advanced models like Whisper, and then applying natural language processing techniques using transformer models such as BART to generate meaningful summaries. Additionally, the system provides multilingual translation and audio output features, making it more accessible and user- friendly. This project highlights how artificial intelligence can simplify content consumption by transforming long videos into short, informative summaries.
